Example code for https://exercism.org in Ruby

Exercism exercises using Ruby (and ports from my Crystal-lang repo)

Version 0.0.1

* Setup
  *L `sudo apt update && sudo apt install gnome-keyring`
  *L `git init`
  * `bundle install --path vendor/bundle`
  *L `sudo apt install ruby-rspec-core`
  *L `sudo apt install rubocop`

* Run tests
  * `rubocop -A`
  * `rspec`
